# Assessment 1 – Web Technology

## KPR Institute of Engineering and Technology (KPRIET)

This repository contains my Web Technology Assessment 1 with five questions implemented using HTML, CSS, and JavaScript.

---

## Questions

### Question 1 – Fundamentals of the World Wide Web

A webpage covering:

- Internet Overview
- Computer Network Concepts
- URL and its Structure
- Domain Name
- Web Browsers and Web Servers
- Working Principle of a Website
- Client-side and Server-side Scripting

**Technology:** HTML, CSS

**File:** `Qn 1.html`

---

### Question 2 – Student Admission Form

A student admission form containing:

- Full Name
- Email
- Mobile Number
- Date of Birth
- Gender
- Course
- 12th Percentage
- Address
- Photo Upload
- College Image
- College Audio
- Submit and Reset buttons

**Technologies:** HTML, CSS

**Files:**

- `Qn 2.html`
- `Qn 2.css`
- `college.jpg`
- `college-audio.mp3`

### Question 3 – StyleHub Fashion Store

A fashion store webpage displaying different products.

**Products:**

| Product | Price |
|---|---:|
| Casual Shirt | ₹799 |
| Women's Dress | ₹999 |
| Sports Shoes | ₹1299 |

**Features:**

- Navigation bar
- Fashion collection section
- 30% offer
- Product cards
- Product images
- Shop Now buttons
- Responsive design
- CSS animation

**Technologies:** HTML, CSS

**Files:**

- `Qn 3.html`
- `Qn 3.css`
- `shirt.jpg`
- `dress.jpg`
- `shoes.jpg`

---

### Question 4 – Student Grade Calculator

A JavaScript-based grade calculator that accepts marks for five subjects and calculates:

- Total marks
- Average
- Grade
- Pass/Fail status

**Grade System:**

| Average | Grade |
|---:|:---|
| 90+ | A+ |
| 80–89 | A |
| 70–79 | B |
| 60–69 | C |
| 50–59 | D |
| Below 50 | F |

A student passes when all subject marks are at least 40.

**Technologies:** HTML, CSS, JavaScript

**Files:**

- `Qn 4.html`
- `Qn 4.css`
- `Qn 4.js`

---

### Question 5 – Supermarket Bill

A JavaScript-based billing system for three products.

It calculates:

- Total amount
- Discount
- Final payable amount

If the total is greater than ₹2000, a 10% discount is applied.

**Technologies:** HTML, CSS, JavaScript

**Files:**

- `Qn 5.html`
- `Qn 5.css`
- `Qn 5.js`
