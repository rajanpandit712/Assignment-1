Fundamentals of the World Wide Web

Understanding how websites and the Internet work

1. Internet Overview

The Internet is a worldwide network of interconnected computers and devices. It allows users to communicate, share information, access websites, send emails and use online services.

2. Fundamental Computer Network Concepts

A computer network connects two or more devices so that they can communicate and share resources.

  • IP Address: Identifies a device on a network.
  • Protocol: A set of rules used for communication.
  • TCP/IP: A collection of protocols used for Internet communication.
  • HTTP/HTTPS: Protocols used for communication between browsers and web servers.

3. URL and its Structure

A URL (Uniform Resource Locator) is the address used to locate a resource on the Internet.

https://www.example.com/products/index.html
  • https: Protocol
  • www: Host/Subdomain
  • example.com: Domain name
  • /products/index.html: Path to the resource

4. Domain Name

A domain name is a human-readable name used to identify a website. It is easier to remember than an IP address.

5. Web Browsers and Web Servers

A web browser is software used to access and display websites. Examples include Google Chrome, Mozilla Firefox and Microsoft Edge.

A web server is a computer or software system that stores website files and sends them to clients when requested.

6. Working Principle of a Website

When a user enters a website address, the browser sends a request to the web server. The server processes the request and sends the required web resources back to the browser. The browser then displays the webpage.

7. Client-side vs Server-side Scripting

Client-side

Runs in the user's browser
Example: JavaScript
Server-side

Runs on the web server
Example: PHP, Python
  • Client-side scripting: Code is executed in the user's browser and is mainly used for interactive user interfaces.
  • Server-side scripting: Code is executed on the server and is used for processing data, authentication and database operations.
